ОТКРЫТЫЕ ИСТОЧНИКИ
Найти информацию о треке
Издания с обложкой показаны первыми. Выберите подходящее: теги попадут в редактор, запись в файл — после сохранения.


Ваша локальная библиотека
База содержит пути к файлам, теги, параметры аудио и обложки. Аудиофайлы остаются в выбранных папках и не копируются в SQLite.
FFTagger проверяет файлы через ffprobe без ограничения по расширению. Скрытые папки, символические ссылки и резервные копии пропускаются. Возможность записи зависит от контейнера.
Поиск в интернете выполняется только по вашей команде. Результаты могут относиться к другому изданию — проверьте их перед сохранением.
Расположение SQLite
FFmpeg


Настройки потоков
Вручную можно выбрать от 1 до 16 потоков. Для медленного HDD или сетевой папки попробуйте уменьшить число потоков.
Настройка действует для сканирования и массовой записи тегов. Сохраняется для следующих запусков; текущая операция продолжится с прежним количеством потоков.


Очистить текущую БД?
Из библиотеки будут удалены все треки, обложки и отчёты о пропущенных файлах. Место в файле БД будет освобождено.
Музыкальные файлы и резервные копии останутся на диске. После очистки папки можно просканировать заново. Список источников, тема и настройка потоков сохранятся.
Несохранённые изменения в редакторе будут сброшены.
Останавливаем сканирование и очищаем библиотеку…


Обновить другие треки альбома?
Текущий трек уже сохранён. Выберите общие изменения и треки, к которым их применить.
Для каждого изменённого файла создаётся резервная копия. Название трека, исполнитель трека, номера трека и диска, композитор и комментарий сохранятся.


Удалить трек?
Файл будет удалён из папки без перемещения в корзину. Трек, его теги и обложка будут удалены из библиотеки.
Резервные копии предыдущих сохранений останутся на диске.
Несохранённые изменения этого трека будут потеряны.
Удаляем файл и запись из библиотеки…
